# Pipeline Design

## Project Name

TrustLens: Seller Performance & Customer Trust Analytics

---

## Pipeline Overview

The project follows an end-to-end data analytics pipeline to transform raw e-commerce marketplace data into actionable business insights through an interactive dashboard.

---

## Data Flow

Raw Dataset
        │
        ▼
Python Data Ingestion
        │
        ▼
Data Cleaning (Pandas)
        │
        ▼
Feature Engineering
        │
        ▼
SQLite Database
        │
        ▼
SQL KPI Queries
        │
        ▼
Streamlit Dashboard
        │
        ▼
Business Insights

---

## Tools Used

| Stage | Tool |
|--------|------|
| Data Ingestion | Python |
| Data Cleaning | Pandas |
| Feature Engineering | Pandas & NumPy |
| Database | SQLite |
| Analysis | SQL |
| Dashboard | Streamlit |
| Version Control | Git & GitHub |
| Automation | GitHub Actions |

---

## Expected Outputs

- Cleaned dataset
- Engineered features
- SQL database
- Business KPI queries
- Interactive dashboard
