# Product Requirements Document (PRD)

## Project Name

TrustLens: Seller Performance & Customer Trust Analytics

---

## Problem Statement

An e-commerce marketplace tracks seller performance, return requests, and customer review sentiment, but lacks a centralized operational dashboard to identify seller behaviors that negatively impact customer trust over time.

---

## Business Objective

Develop an interactive analytics dashboard that enables stakeholders to monitor seller performance, analyze return trends, evaluate customer sentiment, and make informed business decisions.

---

## Target Users

- Marketplace Operations Team
- Business Analysts
- Seller Success Team
- Management

---

## Features

- Data Cleaning
- Feature Engineering
- SQL Analysis
- Interactive Dashboard
- Business KPIs

---

## Success Criteria

- Cleaned and validated dataset
- SQL database created
- Interactive Streamlit dashboard
- Actionable business insights

---

## Constraints

- Python
- Pandas
- SQLite
- Streamlit
- GitHub Actions

---

## Out of Scope

- Machine Learning
- Recommendation Systems
- Real-time Streaming
