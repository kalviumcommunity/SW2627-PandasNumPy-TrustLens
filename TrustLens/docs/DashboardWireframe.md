# Dashboard Wireframe

## Dashboard Goal

Provide business stakeholders with a centralized dashboard to monitor seller performance, return requests, and customer review sentiment.

---

# Dashboard Layout

## Top Section

KPI Cards

- Total Sellers
- Average Seller Rating
- Return Rate
- Positive Review Percentage

---

## Middle Section

Charts

- Seller Performance Ranking (Bar Chart)
- Return Requests by Category (Bar Chart)
- Monthly Return Trend (Line Chart)

---

## Bottom Section

Charts

- Review Sentiment Distribution (Pie Chart)
- Seller Rating Distribution (Histogram)

---

## Sidebar Filters

- Seller Name
- Product Category
- Review Sentiment
- Date Range

---

## Expected Outcome

Users should quickly identify seller behaviors that reduce customer trust.
